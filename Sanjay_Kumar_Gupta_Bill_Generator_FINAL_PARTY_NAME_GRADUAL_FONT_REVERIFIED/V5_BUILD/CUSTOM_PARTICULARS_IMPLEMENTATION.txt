CUSTOM PARTICULARS IMPLEMENTATION

The bill now has four editable blank spaces between the five fixed particulars:
1. Income Tax / Assessment
2. Editable blank space
3. G.S.T
4. Editable blank space
5. Appeal
6. Editable blank space
7. Drafting
8. Editable blank space
9. Miscellaneous

Each editable blank space accepts:
- Particular / service name entered by the user
- Amount entered by the user

If both fields in an editable blank space are left empty, that row remains completely blank in the generated PDF.
The amount is printed directly opposite its own particular.
The four editable rows are positioned at the exact midpoints between the five fixed rows.
Custom amounts are included in the automatic Total.

DATA STORAGE

Custom rows are stored in public.bills.custom_items as JSONB.
Run the included supabase_schema.sql (or the custom migration statement in it) once in the existing Supabase project before using cloud save/history with the new fields.
